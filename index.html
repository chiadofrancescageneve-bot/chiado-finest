📦 Distribuzione su GitHub Pages

Tutti i file sono statici (HTML, CSS, JS, icone e manifest) con percorsi relativi. Puoi scaricare l'intero pacchetto pronto all'uso con un solo clic:

Come pubblicare su GitHub Pages in 3 passi:
1. Crea un repository pubblico su GitHub (es. chiado-finest).
2. Carica i file scompattati nella cartella principale (root).
3. Nelle impostazioni del repository, vai su Pages e seleziona come Branch main / root. L'app sarà subito online!
📲

Installa su iPhone o iPad

Per aggiungere Chiado Finest alla schermata home del tuo dispositivo iOS:

  1. Tocca l'icona Condividi (quadrato con freccia verso l'alto ⎋) nella barra inferiore di Safari.
  2. Scorri il menu verso il basso e seleziona Aggiungi alla schermata Home.
  3. Tocca Aggiungi in alto a destra. L'app comparirà tra le tue applicazioni!

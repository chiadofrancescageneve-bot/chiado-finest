# Chiado Finest 🇬🇧
### Web App Didattica e PWA di Lingua Inglese per la Scuola Secondaria di Primo Grado (11-14 anni)

Benvenuto in **Chiado Finest**, un'applicazione didattica creata per supportare studenti e docenti nell'apprendimento e nel consolidamento della lingua inglese (livelli QCER A1, A2, A2+/B1).

---

## 🌟 Caratteristiche Principali

- **100% Statica e Gratuita**: Non richiede server, database, chiavi API né alcuna registrazione.
- **Privacy e Sicurezza per Minori**: Nessun dato personale raccolto, zero pubblicità, conforme alla privacy scolastica.
- **Funzionamento Offline (PWA)**: Grazie al Service Worker e al Web App Manifest, l'app può essere installata come applicazione nativa su smartphone, tablet e PC e usata anche senza connessione internet (in classe o a casa).
- **Correzione Automatica e Feedback Didattico**: Ogni domanda include 4 opzioni e, in caso di errore, una spiegazione in italiano che guida lo studente a comprendere la regola grammaticale o il contesto lessicale.
- **Sintesi Vocale Integrata**: Gli studenti possono cliccare sull'icona dell'altoparlante 🔊 per ascoltare la corretta pronuncia britannica di frasi e vocaboli.
- **3 Livelli di Difficoltà**:
  - 🟢 **Beginner**: 1ª Media (Livello A1)
  - 🟡 **Intermediate**: 2ª Media (Livello A2)
  - 🟣 **Advanced**: 3ª Media (Livello A2+/B1)

### 📐 Grammar (16 Categorie)
1. **Present Simple** (*Abitudini, fatti, routines, 3ª persona singolare con -s*)
2. **Present Continuous** (*Azioni in corso di svolgimento, forma -ing, verbi di stato*)
3. **Past Simple** (*Verbi regolari -ed, verbi irregolari, ausiliare did/didn't*)
4. **Past Continuous** (*Azioni prolungate nel passato con was/were, while e when*)
5. **First Conditional** (*Ipotesi reali future: If + Present Simple, will + base form*)
6. **Present Perfect** (*Have/has + participio passato, ever, never, just, already, yet*)
7. **Second Conditional** (*Situazioni ipotetiche o immaginarie: If + Past Simple, would*)
8. **Must and Have To** (*Obblighi morali, regole esterne, divieti con mustn't e assenza d'obbligo*)
9. **Should / Shouldn't** (*Consigli e raccomandazioni*)
10. **Future with Will** (*Previsioni, decisioni immediate, promesse*)
11. **Countable and Uncountable Nouns** (*Much, many, some, any, little, few*)
12. **Comparativi e Superlativi** (*Forme regolari -er/-est, more/most, irregolari better/worse*)
13. **Past Simple di Be e Have** (*Was/were, had, forme interrogative e negative*)
14. **Possessive Adjectives** (*My, your, his, her, its, our, your, their*)
15. **Articles** (*A, an, the e omissione dell'articolo / zero article*)
16. **Relative Pronouns** (*Who per persone, which per oggetti, where per luoghi, whose per possesso*)

## 🚀 Come Pubblicare Gratuitamente su GitHub Pages (in 2 minuti)

I file del progetto sono già pronti con percorsi relativi (`./`):

1. Accedi a [GitHub](https://github.com/) e crea un nuovo repository pubblico (es. `chiado-finest`).
2. Trascina o carica direttamente i seguenti file e cartelle nella cartella principale (`root`) del repository:
   - `index.html`
   - `style.css`
   - `script.js`
   - `manifest.webmanifest`
   - `service-worker.js`
   - `apple-touch-icon.png`
   - `favicon.svg`
   - la cartella `icons/` (con dentro `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `icon.svg`)
3. Nel tuo repository GitHub, clicca su **Settings** (Impostazioni) > **Pages** (nel menu laterale sinistro).
4. Sotto **Build and deployment**, seleziona:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` (oppure `master`) e cartella `/ (root)`.
   - Clicca su **Save**.
5. Dopo circa 30-60 secondi, GitHub Pages ti fornirà l'URL pubblico (es. `https://tuo-username.github.io/chiado-finest/`).

## 📲 Come Condividere l'App con gli Studenti

1. **In Classe sulla LIM**:
   - Clicca in alto a destra sul pulsante **👨‍🏫 Area Docente & QR**.
   - Inserisci l'URL del tuo sito GitHub Pages se diverso da quello locale.
   - Proietta il **QR Code** sulla Lavagna Interattiva Multimediale (LIM): gli studenti possono inquadrarlo direttamente con la fotocamera del loro smartphone o tablet.
2. **Sul Registro Elettronico (ClasseViva / Axios / Google Classroom)**:
   - Condividi il link diretto con gli studenti e le famiglie per compiti a casa o potenziamento.
3. **Installazione su Dispositivi Mobili**:
   - **Android / Chrome**: Tocca il banner "Installa App" per aggiungere l'icona alla schermata principale come una vera app.
   - **iPhone / iPad (Safari)**: Tocca il pulsante *Condividi* (quadrato con freccia in su) e seleziona *Aggiungi alla schermata Home*.
